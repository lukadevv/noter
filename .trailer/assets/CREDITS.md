# Audio credits

The audio files in this folder are not committed (see `.gitignore`); this list
is, so anyone can fetch the same files again. `pnpm trailer` warns until the
music file has a source URL here.

When a licence asks for attribution (CC BY, Uppbeat), copy the credit line into
the Microsoft Store listing and the GitHub release notes as well.
